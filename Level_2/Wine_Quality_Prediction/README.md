# Task 2 — Wine Quality Prediction

## Project Overview

This project predicts wine quality using machine learning classification techniques.

## Dataset

The dataset contains physicochemical properties of red wine and its quality score.

## Data Preprocessing

- Missing value analysis
- Duplicate detection
- Duplicate removal
- Feature-target separation
- Train-test split
- Classification preparation

## Dataset

Before duplicate removal:

- 1,599 rows
- 12 columns

After duplicate removal:

- 1,359 rows
- 12 columns

## Important Features

The most important features included:

- Alcohol
- Total Sulfur Dioxide
- Sulphates
- Volatile Acidity
- Chlorides
- Fixed Acidity

## Model Performance

Accuracy: **73.53%**

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

The classification model achieved approximately 73.53% accuracy in predicting whether a wine belongs to the Good or Not Good category.
