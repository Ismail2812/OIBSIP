# Task 4 — Google Play Store Analysis

## Project Overview

This project analyzes Google Play Store applications to understand app categories, ratings, reviews, installations, and pricing.

## Dataset

The original dataset contains:

- 10,841 rows
- 13 columns

There were 483 duplicate rows.

After cleaning and removing duplicates:

- 9,660 unique app records

## Data Cleaning

The following preprocessing steps were performed:

- Missing value handling
- Duplicate removal
- Rating cleaning
- Installs conversion
- Price conversion
- Data type correction

## Top Categories

The largest categories included:

- FAMILY
- GAME
- TOOLS
- BUSINESS
- MEDICAL

## Key Findings

Categories with high average reviews included:

- SOCIAL
- COMMUNICATION
- GAME
- VIDEO_PLAYERS
- PHOTOGRAPHY

Categories with high average ratings included:

- EVENTS
- EDUCATION
- ART_AND_DESIGN
- BOOKS_AND_REFERENCE
- PERSONALIZATION

## Free vs Paid Apps

- Free Apps: 8,903
- Paid Apps: 756

The analysis provides insights into Google Play Store app categories, user engagement, ratings, installations, and pricing patterns.
