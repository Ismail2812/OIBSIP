
# Level 1 — Task 4: Sentiment Analysis

## Project Overview

This project focuses on performing sentiment analysis on text data using Python and machine learning techniques.

The objective is to preprocess textual data, extract useful features, train a classification model, and predict sentiment.

## Objectives

- Load and explore the dataset
- Clean and preprocess text data
- Perform sentiment analysis
- Convert text into numerical features
- Train a machine learning classification model
- Evaluate model performance
- Predict sentiment for new text

## Methodology

The project includes the following steps:

1. Data Loading
2. Data Exploration
3. Text Cleaning
4. Text Preprocessing
5. Feature Extraction
6. Model Training
7. Model Evaluation
8. Sentiment Prediction
