# 🟢 Level 1 Projects

## Task 1 — Exploratory Data Analysis on Retail Sales Data

### 📊 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on a retail sales dataset to understand sales patterns, product performance, category performance, profitability, and relationships between numerical variables.

### 🎯 Objectives

* Understand the structure of the dataset
* Explore sales and profit trends
* Identify top-performing products
* Analyze sales by category
* Study relationships between numerical variables
* Visualize important business insights

### 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

### 🔎 Key Analysis

Some important findings from the analysis include:

* **Staples** was among the highest-selling products with **215 units**.
* **Technology** generated approximately **836,154.03** in sales.
* **Furniture** generated approximately **741,999.80** in sales.
* **Office Supplies** generated approximately **719,047.03** in sales.
* The correlation between **Sales and Profit** was approximately **0.479**.
* The correlation between **Discount and Profit** was approximately **-0.219**.

### 📈 Key Skills Demonstrated

* Exploratory Data Analysis
* Data Visualization
* Correlation Analysis
* Business Insights
* Data Interpretation
